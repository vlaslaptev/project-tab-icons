# Project Tab Icons working agreements

- Рабочие ответы и технические заметки писать по-русски. Публичные материалы
  поддерживать на английском.
- Для Project Tab Icons постоянно разрешены Java/JVM-компиляция, сборка и упаковка,
  включая Gradle/gradlew и зависимые задачи, необходимые для ZIP. Повторное
  согласование не требуется; исключение не заканчивается после отдельной задачи.
- Самостоятельные JVM-тесты, линтеры, проверки и Plugin Verifier не запускать,
  не предлагать и не запрашивать на них разрешение. Исходники проверять статически.
- Не расширять совместимость без анализа целевых API. Сохранять настройки,
  пользовательские иконки и очистку обработчиков при отключении плагина.
- Для публичных примеров использовать только демонстрационные проекты и данные.
- В README и презентационных материалах указывать 100+ иконок, без точного счётчика. Сохранять композицию icon-library при расширении каталога.
- Не помещать в Git секреты, локальные настройки IDE, кеши и результаты сборки.
- Публикация, создание удалённых репозиториев и push требуют указания владельца.
