# GitHub media

These are original informational illustrations for Project Tab Icons 0.3.46,
not captures of a running IDE. Frontend, Backend, Tools, branch names and line
counts are demonstration data.

| Asset | Size | Purpose |
| --- | --- | --- |
| `hero-dark.png` / `hero-light.png` | 1600 × 900 | README cover, selected by preferred color scheme |
| `appearance-presets.png` | 1600 × 1000 | Five named preset starting points; Custom is described in text |
| `icon-library.png` | 1600 × 1000 | All 121 actual bundled SVG icons |
| `git-context.png` | 1600 × 1000 | Full/compact branch names and tracked-line counts |
| `social-preview.png` | 1280 × 640 | Repository social preview |
| `logo-512.png` | 512 × 512 | Transparent export of the existing plugin logo |

Corresponding SVG files are editable sources. `manifest.json` records dimensions
and the source plugin version. `preview.html` displays the full gallery locally.
The logo concept is preserved: overlapping colored project windows and a shark.

The artwork, preset names and Git behavior were checked against the source tree.
The gallery simplifies the UI to explain features; it is not a pixel-accurate
representation of every theme or setting. Code and library attribution are in
[third-party notices](../../THIRD_PARTY_NOTICES.md).
