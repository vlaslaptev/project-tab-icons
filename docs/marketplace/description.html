Recognize open projects in macOS window tabs with their icons, outlines and optional colored fills.

  • Use quick actions in Tools and Find Action to edit the current project icon or colors and switch presets, with customizable shortcuts.
  • Give each project group its own icon and colors. Members inherit them automatically, including newly assigned and reopened projects. A separate Group column shows membership; Ungroup restores individual appearance.
  • Project groups are placed together on the left when windows merge, in group-table order, followed by ungrouped tabs. Set fixed member positions, reorder groups with up/down arrows, and use Arrange Tabs by Group in a project tab's context menu to reapply the same order. Manual tab moves remain available afterwards. Save group changes with Apply.
  • Choose Shared background or Joined tabs in Group layout. Both always inherit regular tab dimensions, theme corners, Style settings and theme-aware active/hover colors with a lighter active tab. Shared icons use Style → Size, including when tab icons are hidden. The group's Tab color controls its fill; Outline color controls its outline, with icon color as the Automatic fallback. Group-specific controls include active-card inset, inactive-group dimming, internal dividers, shared-icon visibility, member-icon hiding, group spacing and boundary pipes. Split groups hide shared decoration until Arrange Tabs by Group. Click preview tabs to compare states; save settings in presets and portable styles.
  • Transfer selected presets, SVG categories and editable text icons in JSON bundles without project paths. Preview imports and keep both, replace or skip matching names.
  • Use Save as new preset and Update preset at the right of the Style / Tab layout / Group layout selector. Both remain visible and are enabled when the action is available. Manage user presets… stays at the right edge of the user presets row for duplication and ordering. Narrow windows wrap header actions below the selector.
  • Import an SVG folder as a shared category in the searchable icon library, preserving original colors and keeping copies independent of the source folder.
  • Create text icons such as DB, QA or API, with 1–6 characters, four styles, three font families and custom colors. Edit them later and save them as transparent SVG paths.
  • Use Enable tab customization to switch the plugin on or off without losing your settings. Disabling restores the native tabs and mutes the project table; re-enabling restores available row actions.
  • Restore defaults with one button: medium icons without backgrounds, icon and close button on the left, bottom-only 2 px outlines and 33 px tab height. Project assignments and the global switch are preserved.
  • Custom project icons follow the IDE's existing icon settings, including dark variants.
  • Preview appearance changes in a miniature IDE window with macOS traffic lights, a toolbar, three project tabs, file tabs and an editor fragment at the top of Settings. The labeled Preview section sits above the global switch. Restore defaults is at the bottom left, with status messages on the right.
  • Use IDE theme for this preview window in the Preview header to compare Current and eight bundled IDEA themes. Only the example window changes; the IDE theme, plugin settings and Apply state are preserved. Reopening Settings starts with Current.
  • Choose bottom-only, rounded-corner or full outlines with a thickness from 1 to 6 px.
  • Choose Custom, Default, Filled, Bold, Git or Relax in the Presets row. Style, Tab layout and Group layout stay editable for every preset. Changing an appearance value automatically selects Custom and preserves the other values. The global switch, preview theme and project assignments keep the preset. Existing configurations open as Custom.
  • Custom returns to your last manual appearance after browsing presets. Apply remembers it across IDE sessions; Cancel discards changes to that memory. The global switch, preview theme and project assignments are separate.
  • A small dot marks each unsaved appearance field or project icon/color value. Apply or returning to the saved value clears the mark; tooltips and accessibility explain it.
  • SVG import errors explain the cause and how to fix it, including empty or oversized files, invalid XML, unsupported content and unavailable files. Wrapped messages keep the previous icon selection intact.
  • Style combines Icon, Outline and Fill in compact sections that wrap in narrow windows. Size, initials and letter weight use segmented choices; icon, close-button and Git positions use Left/Right switches. Outline thickness and fill inset use short pixel inputs. Tab layout uses a compact Info row and two columns: Height with Font size, then Close button with Git position. Narrow windows switch to one column. The settings block fits the selected Style, Tab layout or Group layout page instead of retaining the tallest page’s empty space.
  • Default uses medium icons, bottom-only 2 px outlines, 33 px height, the IDE font and the Git branch on the right. Filled uses Small 20 px icons, a full 1 px outline, 12% fill intensity with a 3 px inset and 34 px height. Bold uses 28 px icons, full 4 px outlines, 16 px text and 38 px height. Git uses Default without icons, with Git Branch Compact and Git status on the right. Relax (previously Dzen) has no icons or fill, a bottom-only 1 px outline, 14 px text and 33 px height.
  • Adjust Intensity in Style → Fill from 0% transparent to 100% solid, in one-percent steps. Existing settings default to 50%. Filled uses 12%; other presets and Restore defaults use 50%. The fill matches the icon color by default. Active-tab brightness is adjusted after the fill, including at 100% intensity, so selection remains visible. Adjust Inset from 0 to 6 px; outlines and content stay in place. Changes appear immediately in Preview and the color picker sample. Tab fill is off initially and after Restore defaults. Disabling fill preserves its intensity.
  • Toggle Show icons and Show outline independently; dependent controls are disabled without losing their values.
  • Choose Small (20 px), Medium (24 px) or Large (28 px) icons. Display options apply to all projects without changing their SVGs.
  • Position the native close button and project icon independently on the left or right. Short titles stay centered relative to the whole tab; long titles use unoccupied space on the right without moving the icon or close button.
  • Keep project captions centered relative to the whole tab. Choose Project path under Info to display paths; the preview updates immediately.
  • In Tab layout, choose None, Project path, Git branch, Git Branch Compact or Git status under Info. Place the branch to the left or right of the project name. Long branch names keep their ending with a leading ellipsis, with the full branch in the tooltip. Preview both positions live. Default and Restore defaults show the Git branch on the right; Filled, Bold and Relax use None. Git position controls the side for both branch modes and Git status, and is disabled for None and Project path. Existing saved display choices are preserved; without a Git branch the project name stays unchanged.
  • Enable Show Git status next to Git position to display the branch and changed-line counts together, for example Backend [APP-2075] +443 -44. Available for Git branch and Git Branch Compact. Selecting either branch mode under Info enables the checkbox automatically; you can turn it off manually. Re-clicking the active mode preserves your choice. The whole Git group moves to the selected side. Preview updates immediately. None, Project path and the standalone Git status mode disable this checkbox. The Git preset enables the combination; Default and other presets leave the extra status checkbox off.
  • Git Branch Compact keeps the part after the last slash, limited to 13 Unicode characters including a leading ellipsis, preserving the end of long names. The full branch stays in its tooltip and accessibility text.
  • Git status shows added and removed lines, such as +443 -44, in green and red, with a font 3 px smaller than the tab title. It counts saved tracked changes against HEAD in the selected Git root, including staged and unstaged changes; binary/untracked files and unsaved editor text are excluded. Counts refresh in the background through Git4Idea without fetching. Clean is +0 -0; loading is an ellipsis and unavailable counts are a dash. A first commit is required.
  • Preview captions use all available tab space, recalculate on resize and font changes, and keep the full branch whenever it fits. Whole-tab centering applies when Info is None. Git captions use the available area between the controls.
  • Adjust tab height from 30 to 60 px in one-pixel steps.
  • Display icons without plugin-added backgrounds. Existing project SVG files and imported artwork are preserved.
  • Tab backgrounds and bottom outlines follow the current theme's corner geometry.
  • Manage all open projects in a compact table with aligned Icon, Icon color, Outline color and Tab color values that can be edited directly. No search or recent-project list is required.
  • Open the icon grid only when choosing an icon, and color controls only when changing a project color.
  • Search 100+ monochrome icons by name or keyword, filter by category, and scroll through the gallery. The library includes digits 0–9, Roman numerals I–XII, L, C, D and M, uppercase and lowercase Latin and Greek letters, and AI and Ai monograms. AI has horizontal bars on the capital I; Ai uses straight geometric strokes and a square dot. Existing icons are preserved. Preview icons at 20, 24, and 28 px. Letter and numeral artwork uses SVG outlines and needs no installed fonts.
  • Choose any color with the native IDE color picker, enter HEX, or use 14 presets: seven bright colors and seven darker counterparts.
  • Browse a separate gallery of open-project SVGs or import your own; original artwork and colors are preserved.
  • Set independent outline and tab colors for every project, or keep them matched to the icon. Generated initials also support an independent icon color.
  • Imported SVG/PNG icons display Original in Icon color and keep their source artwork unchanged.
  • Preview row drafts and save pending project changes together with Apply; revert a row or reload an external change.
  • Apply saves a standalone SVG in the project's native icon storage. It remains available without the plugin.
  • Switch between Style, Tab layout and Group layout groups. Style sections adapt to one, two or three columns; short windows scroll vertically. Presets sit above Preview in a single radio-button group. Group layout separates icon, outline, and spacing/separator controls. Choose A (one letter), AB (Backend → BA) or Ab (Backend → Ba), and Normal or Bold letter weight under Style → Icon. Generated letters update immediately in the Backend preview tab, project table and color dialog; Apply updates window tabs. SVG/PNG artwork is preserved. Two mixed-case bold initials (Ab) are the default for new settings, Restore defaults, all appearance presets and older settings without an initials option. Explicitly saved choices are preserved.
  • Custom artwork is rendered by the IDE at its selected size and display pixel density.
  • Icons follow the corresponding project when switching between merged windows.
  • Disabling the plugin restores the previous tab icons, borders, and layouts.

Requires macOS and IntelliJ IDEA 2026.2.3 or a later update in the 2026.2 branch, with multiple project windows merged into window tabs. The plugin starts when a project opens. Manage all open projects under Settings → Appearance & Behavior → Project Tab Icons, or keep using the IDE's standard project icon chooser. Project names are preserved.

Applying a new SVG replaces the selected project's light and dark icon variants. Selection is previewed before saving; externally changed icons are checked before replacement.

Generated SVGs use the selected color for their outlines. Custom SVG/PNG artwork uses its dominant opaque color, and generated initials use the first background gradient color. The interface is in English.

No accounts, telemetry, or independent network requests are used.
