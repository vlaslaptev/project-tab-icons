# Project Tab Icons

**Узнавайте нужный проект ещё до того, как прочитаете его имя.**

Иконки, цветные линии, полупрозрачная заливка и Git-информация на **оконных вкладках
macOS** в IntelliJ IDEA. Каждому проекту — свой образ, рядом с именем — полезный контекст.

| --- | --- | --- | --- |

Независимый экспериментальный плагин с распространением через GitHub.
Использует внутренние API IntelliJ; поддерживается только **ветка 2026.2**.
Оформляет вкладки **окон проектов** после их объединения, а не вкладки файлов
редактора. Перед установкой прочитайте [ограничения](docs/COMPATIBILITY.md).

## Главное

- **Свой значок для каждого проекта.** 121 встроенный силуэт, импорт SVG,
  галерея SVG открытых проектов и оформление автоматических инициалов.
- **Независимые цвета.** Значок, линия и заливка могут совпадать или иметь разные цвета.
- **Настраиваемая геометрия.** Размер и положение иконки, сторона крестика,
  высота вкладки, толщина линии и размер шрифта.
- **Git рядом с названием.** Полная или компактная ветка, добавленные и удалённые
  строки, положение до или после имени. Нужна интеграция Git4Idea.
- **Превью перед Apply.** Пресеты, темы предпросмотра и сохранение по кнопке.
  Общий выключатель возвращает штатное оформление оконных вкладок.

## Установка

Первый устанавливаемый GitHub Release готовится. Исходники и документация уже
доступны; ZIP плагина появится в [Releases](https://github.com/vlaslaptev/project-tab-icons/releases).

После публикации релиза:

1. Скачайте `project-tab-icons-0.3.46.zip` из **Releases**.
   Это неподписанный плагин для ручной установки.
2. Откройте **Settings → Plugins → ⚙ → Install Plugin from Disk…**, выберите ZIP.
3. Перезапустите IDE, если она предложит это сделать.
4. Откройте несколько проектов отдельными окнами и выберите **Window → Merge All Project Windows**.
5. Откройте **Settings → Appearance & Behavior → Project Tab Icons**.

Выберите пресет, назначьте иконки и нажмите **Apply**.
[Подробная инструкция](docs/INSTALLATION.md).

## От спокойного к заметному

| Пресет | Начальные параметры |
| --- | --- |
| Default | Иконки 24 px, нижняя линия 2 px, вкладки 33 px и Git-ветка справа |
| Filled | Заливка 50%, отступ 5 px, полная рамка 1 px и вкладки 34 px |
| Bold | Иконки 28 px, полная рамка 4 px, шрифт 16 px и вкладки 38 px |
| Git | Без иконок; компактная ветка и число добавленных/удалённых строк |
| Relax | Без иконок и заливки; линия 1 px, шрифт 14 px и вкладки 33 px |
| Custom | Собственное сочетание настроек |

Изменение параметра оформления выбирает **Custom**. Назначения иконок проектов
и тема Preview не меняют выбранный пресет.

## 121 силуэт и ваши цвета

Поиск по имени и ключевым словам, категории, HEX, штатный колорпикер IDEA
и 14 цветовых образцов. Размеры значков — **20, 24 и 28 px**.
Импортированные SVG/PNG сохраняют исходные цвета.

![Встроенная библиотека из 121 SVG](docs/media/icon-library.png)

Выбранные SVG сохраняются в штатном хранилище проектных иконок IDEA и остаются
доступны после удаления плагина. Замена иконки обновляет светлый и тёмный варианты
этого проекта; сохраните собственный оригинал для последующего восстановления.

## Git без лишнего шума

![Настоящее превью настроек: компактные Git-ветки, счётчики строк и контролы Tab layout](docs/media/git-context.png)

Компактный режим берёт часть после последнего `/` и оставляет до 13 Unicode-символов
вместе с многоточием слева. Полная ветка доступна в подсказке.
Счётчик показывает сохранённые **tracked**-изменения относительно `HEAD`, включая
staged и unstaged. Неотслеживаемые и бинарные файлы, несохранённый текст редактора
не учитываются. Это число строк, а не изменённых файлов.

Ветка читается из модели Git в IDE. Строки считаются локально в фоне, без fetch.

## Приватность и устройство

Плагин не требует аккаунта, не содержит аналитики и рекламы и не выполняет
собственных сетевых запросов. [Приватность](PRIVACY.md),
[архитектура](docs/ARCHITECTURE.md), [участие в разработке](CONTRIBUTING.md),
[лицензии ресурсов](THIRD_PARTY_NOTICES.md).

Слайды оформления и Git содержат **настоящие снимки Preview из настроек плагина**.
В них используются встроенные демонстрационные проекты и Git-значения. Обложки
и слайд каталога — иллюстрации; каталог отрисован из настоящих SVG плагина.
[Исходники изображений и происхождение кадров](docs/media/README.md).

Независимый проект, не являющийся официальным продуктом JetBrains.
